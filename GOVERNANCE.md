# Governance

SafeGuard Sentinel uses a maintainer-led governance model during public beta.

Maintainers review issues and pull requests, set release scope, enforce the
project's privacy and safety boundaries, and may decline changes that create
unbounded operational, legal, security, or abuse risk. Significant technical
decisions should be documented in an issue or pull request so the rationale is
publicly reviewable.

Contributors gain broader responsibility through sustained, constructive work,
sound technical judgment, and consistent care for privacy and human oversight.
Repository administration, release publishing, and security-response access
remain limited to explicitly designated maintainers.

Security and conduct reports may be handled privately. All other project
decisions should default to public discussion.
