# Support

SafeGuard Sentinel is a public-beta reference implementation maintained on a
best-effort basis.

Use GitHub issues for reproducible bugs and focused feature requests. Search
existing issues first and include a minimal synthetic reproduction, the
revision, and your Node.js and npm versions.

The project does not provide production deployment support, incident response,
legal advice, compliance certification, model validation, or service-level
commitments. Adopters remain responsible for their AWS architecture, policies,
data handling, human-review process, and operations.

Never include credentials, personal data, production records, private
endpoints, or vulnerability details in a support issue. Security reports must
follow [SECURITY.md](SECURITY.md).
